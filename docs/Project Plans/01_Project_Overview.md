# Tank AI Battle Project --- Overview

## Goal

Create a fun, competitive, and visually engaging 2D top‑down tank battle
environment playable by humans and bots (Python & C++), supporting fog
of war, sensors, and tactical gameplay similar in spirit to Wii Tanks.

## Core Features

-   Top‑down 2D smooth movement
-   Human and AI playable
-   Fog of war with persistent terrain discovery
-   Vision + Radar perception model
-   Ricochet bullets (single bounce)
-   Tactical, medium‑speed projectiles
-   Multi‑mode gameplay (duel, arena, level mode)
-   Visual debugging and observer mode
-   Fair bot timing (language independent)

## Long‑Term Vision

-   Bot tournaments
-   Reinforcement learning compatible
-   Genetic / evolving bots
-   Advanced sensors and special weapons
